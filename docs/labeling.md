# Правила ручної розмітки

Розмітка: `eval/labelset.csv`, колонка `label`; інструмент: `python -m eval.label_cli`.
Розмічали за заголовком і описом, без підказок про джерело (назва фіда в файл не потрапляє).

| Клавіша | Мітка | Що сюди входить |
|---|---|---|
| 1 | programming | софт, IT, ШІ, кібербезпека, технології й техпродукти |
| 2 | economics | економіка, бізнес, фінанси, ринки, компанії, торгівля |
| 3 | design | дизайн, UX/UI, архітектура, мистецтво, типографіка |
| 4 | marketing | маркетинг, реклама, SEO, бренд, соцмережі, продажі |
| 5 | science | наука, космос, медичні дослідження, клімат, відкриття |
| 6 | world | політика, війни, вибори, суспільство, міжнародні новини |
| 0 | other | спорт, шоу-бізнес, лайфстайл, здоров'я, усе, що не підходить |

Правила для спірних випадків:
1. Якщо новина на стику двох тем, обираємо ту, про яку текст здебільшого.
2. Якщо за текстом зовсім неясно, про що новина, ставимо `0`.
3. «other» не входить у метрики (baseline не навчений цього класу); кількість таких новин вказуємо у звіті.
4. Розмітку виконує автор самостійно, без підказок від моделей.

*Після завершення розмітки допишіть тут: скільки новин усього, скільки в кожній категорії, скільки «other».*
