# insightflow-ai

![CI](https://github.com/fxhxyz4/insightflow-ai/actions/workflows/ci.yml/badge.svg)

A scheduled news digest agent (topic: Agentic AI).
RSS feeds -> category classification -> ReAct agent with tools -> periodic report.

* **Classification baseline:** TF-IDF + logistic regression (trained on weak labels from topic-specific feeds).
* **AI method:** a local LLM (Phi-4-mini by default, Q4_K_M, CPU), zero-shot, output constrained by a grammar.
* **Agent:** ReAct from scratch (a text loop of Thought/Action/Observation, no frameworks).
* **Agent baseline:** the same model without tools (it cannot see the database, so it makes things up).
* **Two LLMs** (`config/runtime.py::MODELS`) are also compared under the same protocol on the same data.

## Installation (Python 3.12)

```zsh
uv venv --seed --python 3.12 .venv && source .venv/bin/activate
pip install -r requirements.txt
```
The line `--extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu` in `requirements.txt` provides prebuilt `llama-cpp-python` wheels (no compilation).

## Usage

| What | Command |
|---|---|
| Check the feeds | `python -m src.ingest --check` |
| Collect news | `python -m src.ingest` |
| Data snapshot (for reproducibility) | `python -m src.ingest --snapshot` |
| Restore the DB from a snapshot (clean clone) | `python -m src.ingest --restore` |
| Classify news (baseline) and build the digest, no collection | `python -m src.run_daily --no-ingest` |
| Prepare a sample for manual labelling | `python -m eval.make_labelset` |
| Label | `python -m eval.label_cli` |
| Classification evaluation | `python -m eval.eval_classify --models phi qwen3` |
| Confidence intervals of differences (bootstrap) | `python -m eval.compare` |
| Agent evaluation | `python -m eval.eval_agent --models phi qwen3` |
| Tables for the report | `python -m eval.make_tables` (writes `docs/results_tables_ua.md`) |
| Chat with the agent (terminal) | `python -m src.chat --trace` |
| Web interface | `python -m src.web` -> http://127.0.0.1:8000 |
| Daily report | `python -m src.run_daily [--model phi --digest-model phi]` |
| Tests (no model needed) | `python -m pytest -q` |

The same commands are available in the `Makefile` (`make restore`, `make classify`, `make eval-classify`, `make web`, etc.).

**Clean clone, full reproducible run:**

```zsh
python -m src.ingest --restore       # data/news.db from the snapshot
python -m src.run_daily --no-ingest  # categories (snapshots have none) + digest
python -m eval.eval_classify --models phi qwen3 && python -m eval.compare
python -m eval.eval_agent --models phi qwen3 && python -m eval.make_tables
```

The notebook `notebooks/insightflow.ipynb` only runs these modules and shows the results.

## Web interface

A single page with no extra dependencies: the ready digest by category, a question box for the agent with the Thought/Action/Observation steps shown live, and buttons to rebuild the digest and to collect fresh news. Long actions run in the background, one at a time.

```zsh
python -m src.web                       # http://127.0.0.1:8000
docker compose up -d --build web        # http://localhost:8000
WEB_PORT=8081 docker compose up -d web  # if port 8000 is taken
```

The database must be classified before asking the agent (`python -m src.run_daily --no-ingest`).

## Scheduling

* **systemd (Linux):** `deploy/systemd/README.md`.
* **Docker:** `docker compose up -d --build scheduler`. The database (a SQLite file), reports and models live in `./data`, `./reports`, `./models`.
  Web: `docker compose up -d --build web`. Chat: `docker compose run --rm chat`. Browse the DB in a browser: `docker compose --profile tools up db-browser`.

## Reproducibility

* `SEED` in `config/config.py`, `temperature=0`, pinned versions in `requirements.txt`.
* Data: RSS feeds change daily, so the source of truth is the snapshot `data/snapshot/<date>.jsonl` and `eval/labelset.csv`.
  On a clean clone, `python -m src.ingest --restore` creates `data/news.db` from the snapshot, and the evaluations then work.
* The test set was labelled by hand (rules: `docs/labeling.md`). It has 137 news items (another 47 are labelled `other` and are not part of the comparison).

## Results

Full tables: `docs/results_tables_ua.md` (generated by `python -m eval.make_tables`). The written report: `docs/explanatory_note_draft_ua.md`.

| Method | accuracy | macro-F1 | F1 mixed | F1 thematic | s/item |
|---|---|---|---|---|---|
| TF-IDF + LogReg (baseline) | 0.693 | 0.712 | 0.358 | 0.852 | 0.006 |
| Phi-4-mini (Q4_K_M) | 0.752 | 0.738 | 0.714 | 0.734 | 2.2 |
| Qwen3-4B (Q4_K_M) | 0.701 | 0.669 | 0.278 | 0.763 | 3.5 |

Overall, the difference from the baseline is not statistically established (the 95% CIs contain 0). On mixed feeds Phi is better than the baseline: macro-F1 difference +0.356 [+0.088; +0.534]. Agent with tools: Phi 13/15 and Qwen3 13/15 queries, versus 0/15 without tools.
